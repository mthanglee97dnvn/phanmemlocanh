HƯỚNG DẪN TẠO FILE CÀI ĐẶT (Setup.exe) ĐÓNG GÓI SẴN BẰNG GITHUB
================================================================
Làm 1 lần, mất khoảng 10 phút. GitHub sẽ tự "biên dịch" ra file MThanglee_CullCollage_Setup.exe
chứa sẵn mọi thứ (không cần Python, không cần tải gì khi cài). Hoàn toàn miễn phí.

BƯỚC 1 - Tạo tài khoản GitHub
  - Vào https://github.com/signup, đăng ký bằng email, xác nhận email.

BƯỚC 2 - Tạo kho chứa (repository)
  - Bấm dấu "+" ở góc trên bên phải > "New repository".
  - Repository name: photosift      - Chọn "Private" (riêng tư)      - Bấm "Create repository".

BƯỚC 3 - Tải mã nguồn lên
  - Giải nén file photosift_repo.zip trên máy bạn.
  - Trong trang kho vừa tạo, bấm "uploading an existing file".
  - Mở thư mục đã giải nén, chọn TẤT CẢ (Ctrl+A) các mục bên trong: app, build, tools,
    .github, .gitignore, HUONG_DAN_GITHUB.txt rồi KÉO THẢ vào trình duyệt.
    (Thư mục .github là thư mục ẩn: nếu không thấy, trong File Explorer bấm View > Show > Hidden items.)
  - Chờ tải xong, kéo xuống bấm "Commit changes".
  - Kiểm tra: trong kho phải thấy đường dẫn ".github/workflows/build.yml".

BƯỚC 4 - Cho GitHub build
  - Bấm tab "Actions". Nếu có nút "I understand my workflows, go ahead and enable them" thì bấm.
  - Chọn "Build MThanglee CullCollage Setup" ở cột trái > bấm "Run workflow" > "Run workflow".
  - (Mỗi lần tải mã mới lên, nó cũng tự build.)
  - Chờ khoảng 8-15 phút cho tới khi có dấu tick xanh.

BƯỚC 5 - Tải Setup.exe
  - Bấm vào lần chạy vừa xong, kéo xuống mục "Artifacts", bấm "MThanglee_CullCollage_Setup" để tải file .zip.
  - Giải nén ra được MThanglee_CullCollage_Setup.exe (khoảng 150-300 MB). Chạy file này để cài.
  - File này cài được trên mọi máy Windows 10/11 64-bit, KHÔNG cần mạng, KHÔNG cần Python.

NẾU BỊ LỖI (dấu X đỏ)
  - Mở lần chạy bị lỗi, bấm vào bước màu đỏ, chụp màn hình gửi cho Claude để sửa.

LƯU Ý
  - Windows SmartScreen có thể hiện bảng "Windows protected your PC" vì file chưa ký số:
    bấm "More info" > "Run anyway".
  - Phần chạy thử tự động trong quy trình build (selftest + khởi động máy chủ) giúp biết sớm nếu gói đóng sẵn bị thiếu thư viện.
