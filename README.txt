MThanglee KeyGen cho iPhone/iPad (ứng dụng web - PWA)

Đây là bản KeyGen chạy trên iOS, tạo key GIỐNG HỆT KeyGen trên máy tính (cùng khóa Ed25519, cùng định dạng).
Toàn bộ xử lý nằm trên máy, không gọi mạng, KHÔNG chứa khóa bí mật.

Lần đầu dùng:
1) Mở app, chọn "Khôi phục từ bản sao lưu": dán nội dung file MThanglee_KeyGen_sao_luu_khoa.json
   (tải từ KeyGen trên máy tính, mục "Khóa & sao lưu" > "Tải file sao lưu") và nhập mật khẩu.
2) Sau đó tạo key như trên máy tính: nhập mã máy khách gửi (hoặc "mọi máy"), chọn thời hạn, bấm Tạo key.

Cảnh báo: iPhone có thể xóa dữ liệu của web app khi máy thiếu bộ nhớ. Luôn giữ sẵn file sao lưu khóa.
Không đưa file sao lưu hay mật khẩu cho bất kỳ ai.
